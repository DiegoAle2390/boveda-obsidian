# Bóveda Obsidian — Mapa

Organización híbrida PARA + numeración: lo que está arriba es lo más accionable.

| Carpeta | Para qué |
|---|---|
| `00-Inbox` | Captura rápida, sin procesar. Vaciar seguido. |
| `01-Proyectos` | Proyectos activos, una carpeta cada uno. Usar `_plantilla`. |
| `02-Areas` | Responsabilidades continuas (escuela, negocio, infraestructura, formación). |
| `03-Recursos` | Conocimiento de referencia reutilizable. |
| `04-Decisiones` | ADR: una decisión por archivo. |
| `05-Plantillas` | Templates de nota, ADR, spec y reunión. |
| `06-Bitacora` | Una nota por día. |
| `07-Reuniones` | Notas de reuniones. |
| `08-Estudio` | Apuntes de lo que estoy aprendiendo. |
| `09-Archivo` | Terminado o descartado. |

## Flujo
1. Todo entra por `00-Inbox`.
2. Se clasifica: proyecto, área, recurso o archivo.
3. Las decisiones técnicas importantes se registran como ADR.

## Comandos de Claude
- `/bitacora` — crea o completa la nota del día.
- `/adr <título>` — crea un ADR desde la plantilla.
